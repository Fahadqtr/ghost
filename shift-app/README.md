# تطبيق إدارة الورديات — قسم العمليات الجمركية

تطبيق هاتف لإدارة ورديات الموظفين والإجازات، محوّل من ملف الإكسل الأصلي.
يعمل بالكامل داخل المتصفح، يُحفظ على الجهاز، ويعمل دون إنترنت بعد أول فتح.

## المزايا
- **لوحة معلومات**: حالة اليوم (عاملون/مُجازون)، تنبيه نقص التغطية، الإجازات القادمة، وعدالة توزيع الإجازات.
- **الموظفون**: تسجيل موظف جديد، تعديل بياناته، أو شطبه (يُحذف من الجدول وتُحذف إجازاته).
- **جدول الورديات**: يُولَّد تلقائياً من دورة **6 عمل / 4 راحة** (صباح/عصر/ليل)، مع إمكانية **تعديل أي خانة يدوياً** بالضغط عليها.
- **الإجازات**: حجز/تعديل/حذف الطلبات مع فحص التغطية (أقصى عدد مُجازين في اليوم) وحالة الطلب (معتمد/قيد الانتظار/مرفوض).
- **كشف يومي**: كشف قابل للطباعة أو الحفظ PDF لأي تاريخ.
- **الإعدادات**: طول الدورة والراحة، الحد الأدنى للعاملين، أقصى مُجازين/يوم، وردية بداية الفريق، وزر استرجاع البيانات الأصلية.

## الاستضافة على GitHub Pages
يوجد Workflow جاهز (`.github/workflows/shift-app-pages.yml`) ينشر هذا المجلد تلقائياً على GitHub Pages بعد دمج التغييرات في `master`.

- الرابط الناتج: **`https://fahadqtr.github.io/ghost/`**
- خطوة لمرة واحدة إن لزم: من إعدادات المستودع → **Pages** → **Source: GitHub Actions**.
- لتشغيل النشر يدوياً: تبويب **Actions** → «نشر تطبيق الورديات على GitHub Pages» → **Run workflow**.

## التثبيت على الهاتف
1. افتح رابط Pages أعلاه في متصفح الهاتف.
2. من قائمة المتصفح اختر **«إضافة إلى الشاشة الرئيسية»** — يعمل بعدها كتطبيق مستقل دون إنترنت.

## البيانات
تُحفظ نسخة العمل في `localStorage` على الجهاز نفسه (لا تُرسل لأي خادم). البيانات الابتدائية في `seed.js` مستخرجة من ملف الإكسل الأصلي.

## المعاينة محلياً
```bash
cd shift-app
python3 -m http.server 8099
# ثم افتح http://localhost:8099
```

## البنية
| الملف | الوظيفة |
|------|---------|
| `index.html` | هيكل الواجهة |
| `styles.css` | التنسيق (عربي RTL، تصميم للهاتف) |
| `seed.js` | البيانات الابتدائية من الإكسل |
| `app.js` | منطق الورديات والإجازات والواجهة |
| `sw.js` + `manifest.webmanifest` | العمل دون إنترنت + التثبيت كتطبيق |
