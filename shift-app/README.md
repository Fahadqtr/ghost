# تطبيق إدارة الورديات — قسم العمليات الجمركية

تطبيق هاتف لإدارة ورديات الموظفين والإجازات، محوّل من ملف الإكسل الأصلي.
واجهة عربية للهاتف، **مزامنة سحابية لحظية بين كل الأجهزة** عبر Supabase، مع عمل دون إنترنت.

## المزايا
- **تسجيل دخول آمن**: الوصول للبيانات لمن يملك حساباً فقط (Supabase Auth + RLS).
- **مزامنة بين الأجهزة**: أي تعديل يظهر فوراً على بقية الأجهزة. تعمل التعديلات دون إنترنت وتُرسل تلقائياً عند عودة الاتصال (طابور محلي).
- **لوحة معلومات**: حالة اليوم (عاملون/مُجازون)، تنبيه نقص التغطية، الإجازات القادمة، وعدالة توزيع الإجازات.
- **الموظفون**: تسجيل موظف جديد، تعديل بياناته، أو شطبه (يُحذف من الجدول وتُحذف إجازاته).
- **جدول الورديات**: يُولَّد تلقائياً من دورة **6 عمل / 4 راحة** (صباح/عصر/ليل)، مع **تعديل أي خانة يدوياً** بالضغط عليها.
- **الإجازات**: حجز/تعديل/حذف الطلبات مع فحص التغطية وحالة الطلب (معتمد/قيد الانتظار/مرفوض).
- **كشف يومي**: قابل للطباعة أو الحفظ PDF لأي تاريخ.
- **الإعدادات**: طول الدورة والراحة، الحد الأدنى للعاملين، أقصى مُجازين/يوم، وردية بداية الفريق، وتغيير كلمة المرور.

## المزامنة السحابية (Supabase)
- الاتصال معرّف في `config.js` (مفتاح publishable — علنيّ بطبيعته، والحماية عبر تسجيل الدخول).
- الجداول: `employees` / `leaves` / `overrides` / `settings`، جميعها بـ RLS يسمح للمسجّلين فقط، ومفعّل عليها البث اللحظي (Realtime).
- المعرّفات من نوع UUID تُولَّد على الجهاز لتعمل المزامنة دون تعارض حتى مع التعديل دون إنترنت.

### الأدوار
- **مشرف (admin)**: دخول باسم مستخدم وكلمة مرور، صلاحية كاملة (تعديل الموظفين والجدول والإجازات والإعدادات).
- **موظف (viewer)**: دخول **بالرقم الوظيفي فقط** من صفحة دخول منفصلة، **عرض فقط** لجدول الورديات والكشف اليومي.
  - رابط مباشر لصفحة الموظفين: أضف `?staff` لرابط التطبيق، أو اضغط «دخول الموظفين بالرقم الوظيفي» في شاشة الدخول.
- الحماية على مستوى قاعدة البيانات (RLS): الموظف يقرأ فقط ولا يستطيع الكتابة حتى لو حاول، والتمييز عبر `app_metadata.role`.

### الحسابات
- تُدار من لوحة Supabase (Authentication → Users). المشرف له `app_metadata.role = admin`؛ الموظف يُنشأ ببريد `e<الرقم>@shift.local` وكلمة مرور = الرقم الوظيفي.
- تغيير كلمة مرور المشرف من التطبيق: **الإعدادات → تغيير كلمة المرور**.

### التسجيل التلقائي والأرشفة (تلقائي عبر قاعدة البيانات)
- **إضافة موظف** من التطبيق تُنشئ له حساب دخول (عرض فقط) تلقائياً — يدخل برقمه الوظيفي فوراً.
- **تعديل** الاسم أو الرقم يزامن حساب الموظف تلقائياً.
- **شطب موظف** يؤرشف بياناته وإجازاته في جدولَي `archived_employees` / `archived_leaves` ثم يُلغي حساب دخوله.

### الهوية والشعار
- الثيم بالهوية العنّابية للجمارك القطرية. لإظهار الشعار الرسمي، ضع الملف في `icons/customs-logo.png` (يظهر تلقائياً، وإلا يظهر شعار بديل).

### الجدول
- يفتح على شهر **اليوم** ويمرّر تلقائياً إلى عمود اليوم (مميّز بالعنّابي)، ويعمل لأي مدى زمني (سنوات).
- زر **«أقرب وردية»**: يقفز ويُبرز أقرب وردية قادمة — للموظف ورديته، وللمشرف أقرب يوم عمل للفريق.

## الاستضافة على GitHub Pages
Workflow جاهز (`.github/workflows/shift-app-pages.yml`) ينشر هذا المجلد على GitHub Pages عند الدمج في `master`.
- الرابط: **`https://fahadqtr.github.io/ghost/`**
- خطوة لمرة واحدة إن لزم: إعدادات المستودع → **Pages** → **Source: GitHub Actions**.

## التثبيت على الهاتف/الكمبيوتر
1. افتح رابط Pages في المتصفح وسجّل الدخول.
2. اختر **«إضافة إلى الشاشة الرئيسية»** (هاتف) أو أيقونة **تثبيت** في شريط العنوان (كمبيوتر) — يعمل بعدها كتطبيق مستقل.

## البنية
| الملف | الوظيفة |
|------|---------|
| `index.html` | هيكل الواجهة + شاشة الدخول (النسخة المتزامنة) |
| `styles.css` | التنسيق (عربي RTL، تصميم للهاتف) |
| `config.js` | رابط ومفتاح Supabase |
| `cloud.js` | طبقة المزامنة: الدخول، التحميل، البث اللحظي، الطابور المحلي |
| `app.js` | منطق الورديات والإجازات والواجهة |
| `seed.js` | إعدادات افتراضية احتياطية |
| `sw.js` + `manifest.webmanifest` | العمل دون إنترنت + التثبيت كتطبيق |
| `preview.html` | نسخة ملف واحد **محلية فقط** (بدون مزامنة) للمعاينة السريعة دون خادم |
